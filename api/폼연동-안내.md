# 방문예약 → 휴대폰 문자(SMS) 알림 연동 안내

홈페이지 폼이 제출되면 **김수진 과장(010-8114-4638)** 휴대폰으로 문자가 오도록 설정합니다.
서버 없이 **구글 계정 + 문자 API** 만으로 동작합니다. 순서대로 15~20분이면 됩니다.

---

## 준비물

1. 구글 계정 (Gmail)
2. 알리고(aligo) 계정 — 문자 발송 대행. 건당 약 9~30원, 소액 충전식.
   가입: https://smartsms.aligo.in

---

## STEP 1. 문자 발송용 계정 (알리고)

1. https://smartsms.aligo.in 회원가입 → 로그인
2. **발신번호 사전등록** 메뉴에서 `010-8114-4638` 을 등록
   (통신사 규정상 등록된 번호로만 발송 가능. 신분증/통신가입증명 필요, 보통 당일 승인)
3. 좌측 **[문자 API]** → **API Key** 발급. 아래 3가지를 메모:
   - `API Key`
   - `아이디`(로그인 아이디)
   - `발신번호` = `01081144638`
4. **충전** 메뉴에서 1만 원 정도 충전 (약 300~1,000건 분량)

> 알리고 대신 네이버 클라우드 SENS, NHN Cloud 등을 써도 되지만
> `apps-script.gs` 의 `_sendSms()` 함수를 해당 API 규격으로 바꿔야 합니다.

---

## STEP 2. 접수 내용을 담을 구글 시트

1. https://sheets.google.com 에서 새 스프레드시트 생성 → 이름: `북전주 광신프로그레스 접수`
2. 주소창의 URL 에서 시트 ID 복사
   `https://docs.google.com/spreadsheets/d/`**`이부분이_시트ID`**`/edit`

---

## STEP 3. Apps Script 붙여넣기

1. https://script.google.com → **새 프로젝트**
2. 기본 `Code.gs` 내용을 모두 지우고, 같은 폴더의 **`apps-script.gs`** 내용을 전부 붙여넣기
3. 상단 `CONFIG` 부분을 실제 값으로 채우기:

   ```js
   ALERT_TO:    '01081144638',          // 문자 받을 번호 (그대로 두면 됨)
   ALERT_EMAIL: '',                     // 이메일 사본도 원하면 주소 입력
   SHEET_ID:    'STEP2에서 복사한 시트 ID',
   SHEET_NAME:  '접수',
   ALIGO: {
     key:    'STEP1의 API Key',
     user_id:'STEP1의 아이디',
     sender: '01081144638'
   }
   ```
4. 💾 저장 (Ctrl+S)

---

## STEP 4. 문자 테스트

1. 함수 선택 드롭다운에서 **`_test`** 선택 → **실행(▶)**
2. 처음 실행 시 권한 동의 창이 뜸 → 본인 구글계정 선택 →
   "고급" → "(프로젝트명)(으)로 이동" → 허용
3. `010-8114-4638` 로 테스트 문자가 오면 성공

---

## STEP 5. 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 유형(⚙️) → **웹 앱**
3. 설정:
   - 설명: `북전주 접수 v1`
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**  ← 반드시 이걸로
4. **배포** → 나오는 **웹 앱 URL** 복사
   (`https://script.google.com/macros/s/AKfycb...../exec`)

---

## STEP 6. 홈페이지에 URL 연결

`site/index.html` 에서 아래 줄을 찾아 (약 1000번째 줄, `id="leadForm"`):

```html
<form class="form" id="leadForm" ... data-endpoint="">
```

`data-endpoint=""` 안에 STEP 5의 웹 앱 URL 을 붙여넣습니다:

```html
<form class="form" id="leadForm" ... data-endpoint="https://script.google.com/macros/s/AKfycb...../exec">
```

저장 후 홈페이지에서 폼을 실제로 한 번 제출해 보세요.
→ 구글 시트에 줄이 추가되고 + 담당자 폰에 문자가 오면 완료입니다.

---

## 수정할 때

- **코드(`apps-script.gs`)를 고친 경우** → 반드시 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**
  (새 배포를 또 만들면 URL 이 바뀌니, 기존 배포를 "새 버전"으로 업데이트하세요.)
- 문자 문구를 바꾸려면 `_sendSms()` 의 `var msg = ...` 부분을 수정.
- 문자 대신 카카오 알림톡을 쓰려면 알리고 알림톡(별도 템플릿 심사) 또는
  네이버 SENS 알림톡으로 `_sendSms()` 를 교체.

---

## 문자 없이 이메일 알림만 원하면

STEP 1(알리고)을 건너뛰고 `CONFIG.ALERT_EMAIL` 에 담당자 이메일만 넣으면,
제출 때마다 이메일이 옵니다. 스마트폰 메일 앱의 푸시 알림이 사실상 알람 역할을 합니다.
(단, "문자"로 받는 것보다 즉시성은 떨어질 수 있습니다.)

## 개인정보 관련 체크

- 폼에서 이미 **[필수] 개인정보 수집·이용 동의**를 받고 있습니다.
- 구글 시트/알리고에 성명·연락처가 저장되므로, `privacy.html` 의
  **수탁업체** 표에 `알리고(문자 발송)` 와 `Google LLC(데이터 보관)` 를 추가해 두세요.
- 접수 데이터는 분양 종료 후 6개월 내 파기(시트 행 삭제 + 알리고 발송내역 삭제).
