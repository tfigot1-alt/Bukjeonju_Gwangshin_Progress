# 방문예약 폼 → 구글 시트 자동 저장 연동 안내

홈페이지 방문예약·관심고객 등록 폼을 제출하면 **성함, 연락처, 희망 방문일시,
개인정보 동의 여부**(및 그 밖의 입력값)가 구글 시트에 자동으로 한 줄씩 저장됩니다.
서버를 따로 두지 않고 **구글 계정만으로** 동작하며, 10분이면 끝납니다.
문자(SMS) 알림은 선택 사항입니다(아래 STEP 4).

---

## 배포 환경 안내 (읽고 시작하세요)

이 홈페이지는 **GitHub Pages**(정적 파일 호스팅)에서 서비스됩니다. 서버 실행 환경이
없기 때문에 "환경변수"를 이 저장소 안에 둘 방법 자체가 없고, `index.html`/`js/*.js`
에 적히는 모든 내용은 **누구나 브라우저에서 볼 수 있습니다.** 그래서 이 구조는:

- **API 키·구글 시트 ID 등 민감정보** → 절대 `index.html`/`js/*.js`/이 저장소에 두지 않습니다.
  전부 **Google Apps Script 프로젝트의 "스크립트 속성"**(Google 서버에만 저장되는 값)에 넣습니다.
- **홈페이지(main.js)가 아는 건 딱 하나, "웹앱 실행 주소"뿐**입니다. 이 주소는 폼 제출을
  받는 창구일 뿐 그 자체로는 시트 내용을 읽거나 키를 알아낼 수 없어 공개되어도 무방합니다.
- 즉 "저장은 Google 서버(Apps Script)에서, 화면은 GitHub Pages에서" 로 역할이 나뉩니다.

---

## 준비물

- 구글 계정 (Gmail) 1개만 있으면 됩니다.

---

## STEP 1. 접수 내용을 담을 구글 시트

1. https://sheets.google.com 에서 새 스프레드시트 생성 → 이름: `북전주 광신프로그레스 접수`
2. 주소창의 URL 에서 시트 ID 복사
   `https://docs.google.com/spreadsheets/d/`**`이부분이_시트ID`**`/edit`

---

## STEP 2. Apps Script 붙여넣기

1. https://script.google.com → **새 프로젝트**
2. 기본 `Code.gs` 내용을 모두 지우고, 같은 폴더의 **`apps-script.gs`** 내용을 전부 붙여넣기
   (이 파일에는 API 키를 직접 적는 칸이 없습니다 — 값은 다음 단계에서 별도로 등록합니다)
3. 💾 저장 (Ctrl+S)

---

## STEP 3. 스크립트 속성에 시트 ID 등록 (여기에만 값을 적습니다)

1. Apps Script 편집기 좌측 **⚙ 프로젝트 설정** 클릭
2. 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
3. 속성 이름 `SHEET_ID`, 값에 STEP 1에서 복사한 시트 ID 붙여넣기 → **저장**

> 이 값은 Google 서버에만 저장됩니다. 깃허브 저장소나 `apps-script.gs` 파일에는
> 이 값이 절대 나타나지 않습니다.

---

## STEP 4. (선택) 문자(SMS) 알림도 받고 싶다면

문자 발송은 필수가 아닙니다. 시트 저장만으로 충분하면 이 단계는 건너뛰고 STEP 5로 가세요.

1. 알리고(aligo) 가입: https://smartsms.aligo.in
2. **발신번호 사전등록** 메뉴에서 담당자 번호(예: `010-8114-4638`)를 등록
   (통신사 규정상 등록된 번호로만 발송 가능. 신분증/통신가입증명 필요, 보통 당일 승인)
3. **[문자 API]** → API Key 발급
4. **충전** 메뉴에서 소액 충전 (건당 약 9~30원)
5. STEP 3 과 같은 방법으로 스크립트 속성에 아래 3개를 추가:
   - `ALIGO_KEY` = 발급받은 API Key
   - `ALIGO_USER_ID` = 알리고 로그인 아이디
   - `ALIGO_SENDER` = 사전등록한 발신번호 (하이픈 없이, 예: `01081144638`)
6. 필요하면 `ALERT_TO`(문자 받을 번호, 기본값 `01081144638`)도 스크립트 속성으로 재정의 가능

> 문자 대신 **이메일 알림**만 원하면 스크립트 속성에 `ALERT_EMAIL` 하나만 추가하세요.
> 알리고 대신 네이버 클라우드 SENS 등을 쓰려면 `apps-script.gs` 의 `_sendSms()` 함수를
> 해당 API 규격으로 바꾸면 됩니다.

---

## STEP 5. 문자/시트 테스트

1. Apps Script 편집기에서 함수 선택 드롭다운 → **`_test`** 선택 → **실행(▶)**
2. 처음 실행 시 권한 동의 창이 뜸 → 본인 구글계정 선택 →
   "고급" → "(프로젝트명)(으)로 이동" → 허용
3. STEP 1의 구글 시트에 테스트 행이 추가되면 성공
   (`ALIGO_KEY` 를 등록했다면 문자도 함께 옵니다)

---

## STEP 6. 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 유형(⚙️) → **웹 앱**
3. 설정:
   - 설명: `북전주 접수 v1`
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**  ← 반드시 이걸로
4. **배포** → 나오는 **웹 앱 URL** 복사
   (`https://script.google.com/macros/s/AKfycb...../exec`)

이 URL은 비밀값이 아닙니다 — 이 주소로는 시트를 읽거나 속성값을 알아낼 수 없고,
오직 정해진 형식의 폼 데이터를 받아 저장하는 용도로만 동작합니다.

---

## STEP 7. 홈페이지에 URL 연결

`index.html` 에서 아래 줄을 찾아 (`id="leadForm"`):

```html
<form class="form" id="leadForm" ... data-endpoint="">
```

`data-endpoint=""` 안에 STEP 6의 웹 앱 URL 을 붙여넣습니다:

```html
<form class="form" id="leadForm" ... data-endpoint="https://script.google.com/macros/s/AKfycb...../exec">
```

저장 후 홈페이지에서 폼을 실제로 한 번 제출해 보세요.
→ **"방문예약 신청이 완료되었습니다. 담당자 확인 후 안내드리겠습니다."** 메시지가 뜨고
구글 시트에 줄이 추가되면 완료입니다.
(네트워크 오류 등으로 전송 자체가 실패하면 **"일시적인 오류로 신청이 완료되지 않았습니다.
잠시 후 다시 시도해 주세요."** 가 표시됩니다.)

---

## 수정할 때

- **코드(`apps-script.gs`)를 고친 경우** → 반드시 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**
  (새 배포를 또 만들면 URL 이 바뀌니, 기존 배포를 "새 버전"으로 업데이트하세요.)
- 문자 문구를 바꾸려면 `_sendSms()` 의 `var msg = ...` 부분을 수정.
- 접수 완료/실패 메시지 문구를 바꾸려면 `js/main.js` 의 `say(...)` 호출 부분(8번 항목)을 수정.

---

## 개인정보 관련 체크

- 폼에서 이미 **[필수] 개인정보 수집·이용 동의**를 받고 있고, 서버(Apps Script)에서도
  동의하지 않은 제출은 거부합니다(`doPost` 에서 재검증).
- 구글 시트에 동의 여부("동의"/"미동의")가 열로 함께 저장됩니다.
- 알리고를 쓰기로 하면 구글 시트/알리고에 성명·연락처가 저장되므로, `privacy.html` 의
  **수탁업체** 표에 `알리고(문자 발송)` 를 다시 추가하세요(현재는 Google 항목만 있음).
- 접수 데이터는 분양 종료 후 6개월 내 파기(시트 행 삭제 + 알리고 발송내역 삭제).
