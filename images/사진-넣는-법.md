# 📷 사진 넣고 빼는 법

홈페이지 사진은 **`js/photos.js` 파일 하나**로 관리됩니다.
index.html 은 건드릴 필요 없습니다.

---

## 1. 사진 바꾸기

### 방법 A — 같은 파일명으로 덮어쓰기 (가장 쉬움, 코드 수정 없음)

이 `images` 폴더에 아래 **똑같은 이름**으로 새 사진을 저장(덮어쓰기)하면 끝입니다.

| 파일명 | 쓰이는 곳 | 권장 크기 |
|---|---|---|
| `hero-01.jpg` | 첫 화면 — 단지 조감도(항공뷰) | 가로 2400px 이상 |
| `hero-02.jpg` | 첫 화면 — 투시도(석양·야경) | 가로 2400px 이상 |
| `site-plan.jpg` | 배치도 섹션 | 가로 1600px 이상, 흰 배경 |
| `location-map.jpg` | 입지 안내도 | 가로 2000px 이상 |
| `plan-84a.jpg` | 84A 평면도 | 가로 1600px 이상, 흰 배경 |
| `plan-84b.jpg` | 84B 평면도 | 가로 1600px 이상, 흰 배경 |
| `exterior-01.jpg` | 중간 대형 사진 띠(외관) + 갤러리 | 가로 2400px 이상 |
| `community-01.jpg` | 중간 대형 사진 띠(커뮤니티) + 갤러리 | 가로 2400px 이상 |
| `community-02.jpg` | 갤러리 (조경·놀이터) | 가로 1600px 이상 |
| `interior-living.png` | 갤러리 (거실·주방) | 가로 2000px 이상 |
| `interior-bedroom.jpg` | 갤러리 (침실) | 가로 1200px 이상 |
| `og-image.jpg` | 카톡/문자 공유 썸네일 | 1200 × 630px 고정 |
| `favicon.png` | 브라우저 탭 아이콘 | 64 × 64px |
| `apple-touch-icon.png` | 아이폰 홈화면 아이콘 | 180 × 180px |

> 지금 들어 있는 `exterior-01` `community-01/02` `location-map` `plan-84a/b` 등은
> **임시 이미지**입니다. 실제 사진이 준비되면 위 이름으로 덮어쓰세요.

### 방법 B — 다른 파일명으로 넣기

1. `images` 폴더에 아무 이름으로 사진을 넣습니다. (영어·숫자·하이픈 권장)
2. `js/photos.js` 를 메모장으로 열어, 해당 항목의 `file: "images/..."` 를 그 파일명으로 바꿉니다.
3. 저장 후 브라우저 새로고침.

```js
  heroAerial: {
    file: "images/우리회사-조감도-최종.jpg",   ← 이 부분만 바꾸면 됩니다
    alt:  "북전주 광신프로그레스 단지 조감도",
    ...
  },
```

## 2. 사진 빼기 (자리 비우기)

`js/photos.js` 에서 그 항목의 `file` 값을 **빈 따옴표 `""`** 로 바꿉니다.

```js
  locationMap: {
    file: "",     ← 이렇게 비우면 그 자리에 "사진 자리" 안내판만 표시됩니다
    ...
  },
```

---

## 3. 갤러리 사진 추가 / 삭제

`js/photos.js` 맨 아래 `gallery: [ ... ]` 목록에서 `{ ... }` 한 줄이 사진 한 칸입니다.

```js
  gallery: [
    { file: "images/interior-living.png",  alt: "거실",   caption: "거실 · 주방", size: "wide" },
    { file: "images/interior-bedroom.jpg", alt: "침실",   caption: "침실",        size: "tall" },
    { file: "images/exterior-01.jpg",      alt: "야경",   caption: "야경 투시도" },
    // ↓ 줄을 복사해서 붙이면 칸이 늘어납니다. 지우면 칸이 사라집니다.
    { file: "images/community-03.jpg",     alt: "지하주차장", caption: "지하주차장" },
  ],
```

- `size: "wide"` → 가로로 2칸 차지
- `size: "tall"` → 세로로 2칸 차지
- `size` 를 안 쓰면 → 1칸
- `caption` → 사진 위에 마우스를 올리면 뜨는 작은 글자 (생략 가능)

## 4. 주의사항

- 사진 파일은 **이 `images` 폴더 안**에 있어야 합니다.
- 파일명은 **영어·숫자·하이픈(-)** 을 쓰세요. 한글·공백·특수문자는 일부 서버에서 안 열립니다.
- 사진 1장은 **400KB 이하**로 줄이는 것을 권장합니다. (로딩 속도 = 검색 순위)
  온라인 압축: `tinypng.com` / `squoosh.app`
- 조감도·투시도·평면도 등 **사업 관련 이미지에는 "실제와 차이가 있을 수 있습니다"** 문구가
  자동으로 함께 표시됩니다. 임의로 지우지 마세요 (표시·광고 심의 관련).
